# Cherry V2.0 Documentation

This directory contains the source-of-truth documents for the V2.0 redesign.

## Start here

1. [`v2/DESIGN_FREEZE.md`](v2/DESIGN_FREEZE.md) — **final design-freeze authority, precedence, and wording corrections**
2. [`v2/IMPLEMENTATION_PLAN.md`](v2/IMPLEMENTATION_PLAN.md) — **phase boundaries, requirement ownership, non-goals, and exit criteria**
3. [`v2/requirements/REQUIREMENTS.md`](v2/requirements/REQUIREMENTS.md) — requirements baseline
4. [`v2/design/BASIC_DESIGN.md`](v2/design/BASIC_DESIGN.md) — module/data/interaction design baseline
5. [`v2/design/TEST_STRATEGY.md`](v2/design/TEST_STRATEGY.md) — verification strategy
6. [`v2/adr/`](v2/adr/) — accepted architecture decisions and decision history

Where an older draft passage conflicts with an accepted ADR or `v2/DESIGN_FREEZE.md`, the accepted ADR/freeze record takes precedence.

## Structure

- `v2/PROJECT_CHARTER.md` — project scope, constraints, and development policy
- `v2/IMPLEMENTATION_PLAN.md` — phased implementation roadmap and gates
- `v2/issues/` — complete Issue inventory and disposition decisions
- `v2/requirements/` — requirements and acceptance criteria
- `v2/design/` — basic design, module boundaries, data flow, UI/system design
- `v2/adr/` — Architecture Decision Records

## V1 documents

V1 documents are intentionally not copied into this branch. They remain available from `main` and Git history.

They may be consulted as evidence, but they are not authoritative for V2 unless their contents are explicitly adopted into a V2 document.
