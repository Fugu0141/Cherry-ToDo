# Cherry V2.0

Cherry V2.0 は、Cherry-ToDo をゼロベースに近い形で再設計する開発ラインです。

V1 の実装構造は V2 にそのまま持ち込みません。V1 のコード・設計・挙動は `main` ブランチと Git 履歴に保存し、V2 の要件確認や互換性検討のための参照資料として扱います。

## 現在のフェーズ

現在は **要件定義・基本設計フェーズ** です。

次の項目が完了するまでは、本格的な機能実装を開始しません。

1. 現在 Open の GitHub Issue をすべて棚卸しする
2. V2.0 で対応する Issue を要件へ落とし込む
3. ドメインモデルとモジュール境界を定義する
4. 依存方向と公開インターフェースを定義する
5. 永続化・データ移行・UI・テスト方針を定義する

## 設計目標

Cherry V2.0 は、小さく独立した部品を明確な契約で組み合わせて動作する構造を目指します。

- 高い再利用性
- 低結合・高凝集
- 明示的な依存関係
- UI から独立してテストできる業務ロジック
- 交換可能な Infrastructure / UI
- 隠れたグローバル状態を持たない
- 安定したデータ契約
- 自動テストによる回帰防止

## ブランチ構成

- `main`: 現行 V1 / 旧実装の参照元
- `v2.0`: V2.0 の統合ブランチ
- `chore/v2-bootstrap`: V2.0 初期整理用の作業ブランチ
- 各設計・実装ブランチ: bootstrap 完了後に `v2.0` から作成

V2 のドキュメント構成は [`docs/README.md`](docs/README.md) を参照してください。
